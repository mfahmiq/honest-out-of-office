# Honest Out-of-Office

A single painfully honest — yet manager-safe — out-of-office auto-reply for the
make.fun bounty "The Painfully Honest Out-of-Office".

> I'm away, and let's be honest: I opened your email, sighed, and closed it — I'll answer properly when I'm back.

One sentence, 111 characters. It admits the private truth (the email was opened,
sighed at, and closed) while still promising a proper reply — honest first,
polite second, quotable third.

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).
